# uPlot 1.6.32 (vendored)

The configurator's Trace view draws its graphs with
[uPlot](https://github.com/leeoniya/uPlot) 1.6.32 by Leon Sorokin, MIT
license (see LICENSE). The files are `dist/uPlot.iife.min.js` and
`dist/uPlot.min.css` from the npm package `uplot@1.6.32`
(tarball sha256 4b8a8191e425658e3ea8c8c1314b0fc679c861ee3a1af2b20c7b16ba50b5133d), unchanged. They are served from the configurator's
own static folder, so the page needs no network.

To update: `npm pack uplot@<version>`, copy the same two files and LICENSE
here and change the version in this file.
