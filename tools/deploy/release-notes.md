PC tools {version} for Windows, macOS and Linux (x86_64 and ARM64). No Python needed: see [docs/install-pc.md](https://github.com/{repo}/blob/deploy-v{version}/docs/install-pc.md).

**Install or update** with one line, which installs [uv](https://docs.astral.sh/uv/) if needed and then this release: `curl -LsSf https://github.com/{repo}/releases/download/deploy-v{version}/install-pc.sh | sh -s -- --version {version}` (macOS, Linux) or `$f = "$env:TEMP\install-pc.ps1"; irm https://github.com/{repo}/releases/download/deploy-v{version}/install-pc.ps1 -OutFile $f; powershell -NoProfile -ExecutionPolicy RemoteSigned -File $f -Version {version}` (Windows PowerShell); without the version it installs the newest release. It installs on Python 3.14 (uv fetches it) and moves an install on an older Python to it. The one-line installer also adds a **canworks configurator** app shortcut that starts the configurator without a terminal (`--no-shortcut` or `-NoShortcut` skips it). By hand: install uv, download `canworks-{version}-py3-none-any.whl` below (one file for every operating system), then run `uv tool install --compile-bytecode --python 3.14 canworks-{version}-py3-none-any.whl`. This puts these commands on PATH: `canworks-config` (configurator), `canworks-deploy` (deploy tool), `canworks-diag` (diagnostics and trace), `canworks-sim-runtime` (local simulator runtime), `canworks-j1939-sim` (J1939 simulator) and `canworks-link` (remote link service, for the runtime host).

**Also in this release**
- `canworks.stlib`: the canworks function block library for OpenPLC Editor (CANopen, CiA 402, CAN and J1939 blocks; [docs/plc-library.md](https://github.com/{repo}/blob/deploy-v{version}/docs/plc-library.md)).
- `ghcr.io/{owner}/canworks-sim-runtime:{version}` (amd64 and arm64): the local simulator runtime, no hardware needed; `canworks-sim-runtime start` pulls it ([docs/local-runtime.md](https://github.com/{repo}/blob/deploy-v{version}/docs/local-runtime.md)).
- `ghcr.io/{owner}/canworks-bridge:{version}` (amd64 and arm64): the Modbus TCP bridge ([docs/modbus-bridge.md](https://github.com/{repo}/blob/deploy-v{version}/docs/modbus-bridge.md)). To install this release's bridge on a Linux device without Docker: `curl -LsSf https://github.com/{repo}/releases/download/deploy-v{version}/install-bridge.sh | sudo bash -s -- --version {version}` (add `--ssh USER@HOST` to run it from a PC).
- `install-pc.sh`, `install-pc.ps1`, `install-runtime.sh`, `install-runtime.ps1`, `install-bridge.sh`, `install-bridge.ps1`: this release's install scripts, which the one-line installers in the README download (PC tools; the runtime plugin; the Modbus bridge; `.sh` for macOS and Linux, `.ps1` for Windows).
- `device-probe.sh`: the read-only check the configurator's Devices workspace runs on a device over SSH (it ships in the PC tools too; [docs/devices.md](https://github.com/{repo}/blob/deploy-v{version}/docs/devices.md)).

Only the newest four releases are kept. To install an older version, see "Older versions" in docs/install-pc.md.
